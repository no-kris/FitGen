# FitGen App

## Introduction

FitGen is a Progressive Web App (PWA) and Capacitor Mobile App designed to generate personalized workout plans using AI and track user progress. The application provides a seamless, cross-device fitness tracking experience, ensuring users can access their workout plans and log their progress from anywhere.

## Key Features

### Personalized AI Workout Generation
- **Customized Plans**: Generates tailored workout programs based on user preferences, including fitness goals, available equipment, and experience level.
- **Adaptive Progression**: Uses AI to generate subsequent weeks of the workout program, adapting based on user feedback and logged progress from previous weeks.

### Workout Execution & Tracking
- **Active Workout Mode**: A dedicated interface for executing daily workouts, featuring exercise instructions, set/rep tracking, and built-in rest timers.
- **Exercise Swapping**: Allows users to easily swap out exercises for suitable alternatives on the fly if equipment is unavailable or an exercise feels uncomfortable.
- **Progress Auto-Save**: Automatically saves workout progress. If the app is closed or reloaded mid-session, users can resume exactly where they left off without losing their data.

### Progress Logging
- **Workout History**: Maintains a comprehensive log of all completed workouts, including the specific exercises performed, weights used, and reps completed.
- **Data Visualization**: Allows users to review past performances to track strength gains and overall consistency.

### Cloud Synchronization & Accounts
- **Seamless Cloud Sync**: Synchronizes workout plans, user profiles, and history across multiple devices securely using the cloud.
- **Flexible Authentication**: Supports standard email/password accounts as well as anonymous "Guest" logins for users who want to try the app before committing to an account.
- **Offline Resilience**: Continues to function and track active workouts even with intermittent internet connectivity, syncing data once the connection is restored.
